# COASTFINDER (bestehendes Repository)

Dieses bereits existierende, öffentliche GitHub-Repository wird für **COASTFINDER FREE** verwendet. Kein neues Repository und keine kostenpflichtigen Dienste nötig.

**Projektziel:** Angelspot-Kandidaten an Küsten in Frankreich und Kroatien anhand öffentlicher Geodaten, Wind, Wellen, Strömung und saisonalen Hinweisen entdecken. Fänge und persönliche Notizen bleiben privat im jeweiligen Browser.

## Bereitstellungsstand

Die vollständige V5-Anwendung liegt als **COASTFINDER_V5_KOSTENLOS.zip** im ChatGPT-Projekt vor und soll im Root dieses Repositories (Inhalt des ZIP-Ordners `COASTFINDER_FREE/`) abgelegt werden. Ein vollständiger Upload der Anwendung steht noch aus; diese README ist **keine laufende App**.

Nach Upload der statischen Dateien: GitHub Settings → Pages → Deploy from a branch → main → / (root) wählen. `/.github/workflows/update-feeds.yml` aktualisiert erlaubte öffentliche RSS-Quellen (bei aktivierten GitHub Actions). Keine privaten Exportdateien, Tokens oder Datenbanken committen.

**Kostenregel:** 0 € Pflichtkosten; keine kommerziellen API-Tarife einschalten. Vor öffentlicher Nutzung die realen API-Antworten und Nutzungsbedingungen prüfen.
