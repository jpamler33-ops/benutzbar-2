# GUARDIAN V1 — development branch

This branch is reserved for GUARDIAN, a safety-focused private messenger prototype.

## Status
- Original project preserved on `main` and `backup/pre-guardian-2026-11-21`.
- Starter archive exists separately as `guardian-v1.zip` in the ChatGPT conversation; its application source has **not yet been committed** to this branch.
- No deployment, production ID verification, end-to-end encryption or automated grooming detection is implemented.

## Intended stack
Next.js, TypeScript, Supabase Auth, PostgreSQL Row Level Security.

## Required before public use
Secure authentication, contact controls, abuse reporting, moderation workflows, security testing, privacy and child-safety legal review. Never upload identity documents or real minors' sensitive data to a development environment.
